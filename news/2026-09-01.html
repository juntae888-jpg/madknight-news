④ 오늘의 활용 팁

"요약은 GUI 챗, 실행은 샌드박스" · 웹 콘텐츠 역할 분리

오늘 뉴스의 Claude Code RCE 체인은 '파일 · 셸 권한이 있는 에이전트에게 신뢰할 수 없는 웹페이지를 읽힌 것'이 출발점입니다. 멀티 AI 환경이라면 역할 분리만으로 위험이 크게 줄어듭니다:

출처가 불분명한 URL 요약 · 번역은 코드 실행 권한이 없는 GUI 챗(ChatGPT/Gemini/Claude 웹)에 맡기고, Claude Code · Cowork에는 신뢰하는 리포와 파일만 넘기세요. 에이전트에서 외부 웹을 꼭 읽어야 하면 자동 승인(auto) 모드 대신 권한 프롬프트를 켜두는 것이 안전판입니다.

이미 여러 AI를 GUI로 나눠 쓰고 있다면, "읽기 전용 AI"와 "실행 권한 AI"를 구분하는 습관만 더하면 됩니다.
